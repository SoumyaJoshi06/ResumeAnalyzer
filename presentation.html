AI Pipeline

Where AI is used

1
Profile Extraction
Input: raw resume text → GPT extracts structured candidate data
Output: name, skills[], experience[], education[], projects[]
2
ATS Scoring
Input: raw resume text → GPT scores across 6 dimensions
Output: totalScore + sections (keywords, skills, projects, impact, alignment, clarity)
3
Improvement Suggestions
Input: raw resume text → GPT rewrites the 4–5 weakest bullets
Output: [ { original, improved, reason } ]
4
Skill Gap Analysis (on-demand)
Input: candidate skills + target role requirements → GPT categorises
Output: strong[], partial[], missing[], priorityLearning[]

All prompts return structured JSON only — no free-form text, fully type-safe parsing.

No AI Here — Pure Logic

Role matching algorithm

How it works:
1. GPT extracts candidate skills (Call #1)
2. 10 JD files loaded at startup @PostConstruct
3. For each role: normalize both sides to lowercase
4. Required skills overlap → 80% weight
5. Preferred skills overlap → 20% weight
6. Sort descending → return top 5 matches

Role matching is intentionally designed without AI — it's deterministic, fast, and demo-safe. AI is used only where language understanding is needed.
