## Application Flow

```
User opens http://localhost:5173
        │
        ▼
┌─────────────────┐
│  Landing (/)    │  User selects PDF → clicks "Analyze My Resume →"
└────────┬────────┘
         │  navigate('/loading', { state: { file } })
         │  File object passed via React Router location state
         ▼
┌─────────────────┐
│  Loading        │  POST /api/resume/analyse (multipart)
│  (/loading)     │  Fake step ticker runs in parallel with the real API call
└────────┬────────┘
         │  On success → setAnalysisData(res.data, file.name) into Context
         │  navigate('/dashboard')
         ▼
┌─────────────────────────────────────────────────┐
│  Dashboard (/dashboard)                         │
│                                                 │
│  Tab A — Score          (no API call)           │
│  Tab B — Skills & Gap   (POST /gap on role pick)│
│  Tab C — Roles          (no API call)           │
│  Tab D — Improvements   (no API call)           │
└─────────────────────────────────────────────────┘
         │
         │  "New Analysis" button → clearAnalysis() → navigate('/')
```

**Total API calls: 2**
1. `POST /api/resume/analyse` — once on upload
2. `POST /api/analyse/{sessionId}/gap` — each time user picks a role in Tab B

## API Layer — `src/api/resumeApi.js`

```js
const BASE_URL = 'http://localhost:8080'
```

| Function | Method | Endpoint | Payload | Returns |
|---|---|---|---|---|
| `uploadAndAnalyse(file)` | POST | `/api/resume/analyse` | `FormData` with `file` key | Full analysis response |
| `getSkillGap(sessionId, role)` | POST | `/api/analyse/{sessionId}/gap` | `{ role: "..." }` | `SkillGapReport` |
| `getRoles()` | GET | `/api/analyse/roles` | — | Array of role names |

**`uploadAndAnalyse`** sets `Content-Type: multipart/form-data` so the backend `@RequestParam("file")` can read the PDF.

**`getSkillGap`** sends JSON body — maps to the backend's `@RequestBody Map<String, String>`.

## Global State — `src/context/AnalysisContext.jsx`

### Why Context?
The analysis result from the single `POST /api/resume/analyse` call is used across 4 separate tab components. Passing it down as props through Dashboard → each tab would require prop drilling. Context solves this cleanly.

### What is stored

| Field | Type | Source |
|---|---|---|
| `sessionId` | string | `res.data.sessionId` |
| `profile` | object | `res.data.profile` — name, skills, experience, etc. |
| `scoreCard` | object | `res.data.scoreCard` — totalScore, sections, strengths, criticalIssues |
| `improvements` | array | `res.data.improvements` — original / improved / reason |
| `matchedRoles` | array | `res.data.matchedRoles` — role, matchPercentage, matchedSkills, missingSkills |
| `fileName` | string | Original PDF filename — shown in Dashboard header |

### Key functions

```js
setAnalysisData(data, fileName)   // called once in Loading.jsx after API success
clearAnalysis()                   // called when user clicks "New Analysis"
```

### How components consume it

```jsx
const { scoreCard, profile, matchedRoles } = useAnalysis()
```

`useAnalysis()` is a custom hook wrapping `useContext(AnalysisContext)`.

## Screen 2 — Loading (`src/pages/Loading.jsx`)

**Core challenge:** One API call does all the work, but we want to show progress step-by-step to keep the user engaged.

**Solution — fake step ticker alongside the real API call:**
```js
let step = 0
const interval = setInterval(() => {
  step++
  if (step < STEPS.length - 1) setCurrentStep(step)
}, 2500)

uploadAndAnalyse(file)
  .then((res) => {
    clearInterval(interval)         // stop ticker
    setCurrentStep(STEPS.length)    // mark all done
    setAnalysisData(res.data, file.name)
    setTimeout(() => navigate('/dashboard'), 400)
  })
```

- `step` is a plain variable (not state) — updated by reference inside the interval closure, no stale closure issue
- If API responds before all steps animate, the interval is cleared immediately — no zombie steps
- Cleanup function `return () => clearInterval(interval)` handles unmount safety
- `setTimeout` before navigate gives a brief "all done" flash before switching screens

**Redirect guard:**
```js
const file = location.state?.file
if (!file) { navigate('/'); return }
```
If user hits `/loading` directly (no file in state), they're sent back to Landing.

**Step labels** (`src/components/StepProgress.jsx`) are user-facing, not internal log language:
```
Reading your resume
Extracting skills & experience
Evaluating resume quality
Identifying skill gaps
Matching career roles
```

## Screen 3 — Dashboard (`src/pages/Dashboard.jsx`)

**Tab rendering strategy — all tabs stay mounted:**
```jsx
<div className={activeTab !== 0 ? 'hidden' : ''}><ScoreTab /></div>
<div className={activeTab !== 1 ? 'hidden' : ''}><SkillsTab preSelectedRole={gapRole} /></div>
<div className={activeTab !== 2 ? 'hidden' : ''}><RolesTab onSeeSkillGap={handleSeeSkillGap} /></div>
<div className={activeTab !== 3 ? 'hidden' : ''}><ImprovementsTab /></div>
```

**Why not conditional rendering (`{activeTab === 1 && <SkillsTab />}`)?**
If SkillsTab unmounts every time the user switches tabs, its local state (fetched gap data) is lost. Keeping all tabs mounted with `hidden` class preserves gap data between tab switches.

**Cross-tab navigation — "See Skill Gap" flow:**
```js
const [gapRole, setGapRole] = useState(null)

const handleSeeSkillGap = (role) => {
  setGapRole(role)     // tell SkillsTab which role to pre-select
  setActiveTab(1)      // switch to Skills & Gap tab
}
```
RolesTab calls `onSeeSkillGap(role)` → Dashboard updates `gapRole` → SkillsTab's `useEffect` fires because `preSelectedRole` prop changed → fetches gap for that role.

**Redirect guard:**
```js
useEffect(() => {
  if (!scoreCard) navigate('/')
}, [scoreCard, navigate])
```

## Tab A — Score (`src/components/ScoreTab.jsx`)

**Data source:** `scoreCard` from Context (no API call)

**Circular progress ring:**
```jsx
import { CircularProgressbar, buildStyles } from 'react-circular-progressbar'

<CircularProgressbar
  value={totalScore}
  text={`${totalScore}`}
  styles={buildStyles({ pathColor: color, textColor: color, trailColor: '#e2e8f0' })}
/>
```

**Dynamic colour by score:**
```js
const getColor = (score, max = 100) => {
  const pct = (score / max) * 100
  if (pct >= 71) return '#22c55e'  // green
  if (pct >= 51) return '#f97316'  // orange
  return '#ef4444'                  // red
}
```
Same function used for both the ring and the 6 section progress bars.

**6 section keys mapped to display labels:**
```js
const SECTION_LABELS = {
  atsKeywords: 'ATS Keywords',
  skillsRelevance: 'Skills Relevance',
  projectsExperience: 'Projects',
  impactQuantification: 'Impact / Numbers',
  roleAlignment: 'Role Alignment',
  clarityCompleteness: 'Clarity',
}
```
These match exactly the keys returned by the backend's `ATSScoreCard.ATSSections`.

## Tab B — Skills & Gap (`src/components/SkillsTab.jsx`)

**Data sources:**
- Skill chips → `profile.skills` from Context
- Role dropdown → `matchedRoles.map(r => r.role)` from Context
- Gap columns → `POST /api/analyse/{sessionId}/gap` (live API call per role)

**Auto-load on mount:**
```js
useEffect(() => {
  const roleToLoad = preSelectedRole || roles[0]
  if (roleToLoad) {
    setSelectedRole(roleToLoad)
    fetchGap(roleToLoad)
  }
}, [preSelectedRole])
```
On first open, loads gap for the top-matched role automatically. When `preSelectedRole` changes (user clicked "See Skill Gap" in Roles tab), re-fetches for the new role.

**Gap response shape displayed:**
```
gapData.strong[]          → green column
gapData.partial[]         → orange column
gapData.missing[]         → red column
gapData.priorityLearning[] → numbered cards with skill / reason / resource
```

## Tab C — Roles (`src/components/RolesTab.jsx`)

**Data source:** `matchedRoles` from Context (no API call)

**Per-card structure:**
- Role name + `matchPercentage` as a number
- Horizontal progress bar — colour based on percentage (green ≥80, orange ≥60, red <60)
- Matched skills (green chips) and Missing skills (red chips) in separate labelled groups — max 4 matched, 3 missing
- "See Skill Gap →" button — triggers cross-tab navigation via `onSeeSkillGap` callback prop

**Heading:** `"Roles That Match Your Profile"` — deliberately avoids "eligible for" since the score represents fit, not a hiring qualification.

---

## Tab D — Improvements (`src/components/ImprovementsTab.jsx`)

**Data source:** `improvements` array from Context (no API call)

**Per-card structure:**
- `item.original` — shown in red-tinted box with strikethrough
- `item.improved` — shown in green-tinted box with Copy button
- `item.reason` — small grey italic note below

**Copy to clipboard:**
```js
const handleCopy = (text, index) => {
  navigator.clipboard.writeText(text)
  setCopied(index)
  setTimeout(() => setCopied(null), 2000)
}
```
`copied` state tracks which card's button shows "✓ Copied!" — resets after 2 seconds.

## How to Run

```bash
# Terminal 1 — Backend (from backend/ folder)
set OPENAI_API_KEY=sk-your-key
mvn spring-boot:run

# Terminal 2 — Frontend (from ResumeAnalyzerUI/ folder)
npm run dev
```

Open `http://localhost:5173`

Backend must be running on `http://localhost:8080` — CORS is already configured in `WebConfig.java` for `localhost:5173`.

## Key React Concepts Used

| Concept | Where | What it does |
|---|---|---|
| `useState` | All components | Local UI state — file selection, active tab, gap data, copy state |
| `useEffect` | Loading, SkillsTab, Dashboard | Side effects — API calls, redirect guards, auto-load on mount |
| `useContext` / custom hook | All tab components | Consume global analysis data without prop drilling |
| `useNavigate` | Landing, Loading, Dashboard | Programmatic navigation between screens |
| `useLocation` | Loading | Read `file` object passed via React Router state |
| React Context + Provider | `AnalysisContext` | Share sessionId + full analysis result across all 4 tabs |
| Conditional CSS (`hidden`) | Dashboard | Keep all tabs mounted to preserve fetched gap data |
| Callback props | RolesTab → Dashboard | Cross-tab navigation ("See Skill Gap →" switches tab + pre-selects role) |
| `FormData` | `resumeApi.js` | Send PDF as multipart/form-data to Spring Boot |
| `navigator.clipboard` | ImprovementsTab | Copy improved bullet to clipboard |
| Cleanup in `useEffect` | Loading | `return () => clearInterval(interval)` — prevents memory leaks on unmount |
